# My Personal DSA Dashboard — 30-Day Python Challenge

A beginner-friendly 30-day Data Structures and Algorithms practice plan in Python, running from **November 1–30, 2026**.

## Interactive dashboard

Open [`index.html`](index.html) in your browser. The dashboard includes:
- A clickable 30-day calendar with daily topics and practice links.
- LeetCode and HackerRank problem links for each day.
- Completion checkboxes, filters, and a progress indicator.
- A field to save the link to your DSA study conversation.
- Progress export so you can back up your browser data.

**Progress note:** completion checkmarks and the saved chat URL are stored in your browser's local storage. They do not automatically sync to GitHub or between devices. Use the dashboard's export feature to back up progress, and update the Markdown files in `progress/` when you want to publish your learning notes.

## Daily study routine

Suggested study window: **7:00–9:00 PM IST**.

| Time | Activity |
|---|---|
| 20 minutes | Learn or review the day's concept |
| 45 minutes | Work through the LeetCode problem |
| 10 minutes | Break |
| 30 minutes | Attempt the HackerRank exercise |
| 15 minutes | Review the approach and note time/space complexity |

Try each problem independently first. Understand the input and output, work through a small example, write a basic approach, and then improve it.

## Weekly focus

- **Week 1:** conditionals, loops, number logic, arrays, sets, dictionaries, and revision.
- **Week 2:** strings, frequency maps, two pointers, sliding window, and revision.
- **Week 3:** binary search, sorting, greedy algorithms, heaps, stacks, and queues.
- **Week 4:** linked lists, trees, graphs, recursion/backtracking, dynamic programming, and a final mock.

## Progress logs

Use the matching file in [`progress/`](progress/) to write what you tried, where you got stuck, the key insight, and complexity. Complete a day when you can explain the approach in your own words—not just when you have viewed a solution.

## Publish the dashboard with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/(root)`, then save.
4. After publishing, the site will be available at [`https://nikki03-tech.github.io/my-personal-dsa-dashboard/`](https://nikki03-tech.github.io/my-personal-dsa-dashboard/).
